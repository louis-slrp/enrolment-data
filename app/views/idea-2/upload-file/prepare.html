File name format

Name your file using this format:

MTD-LLLLLLLL-YYYY-WW-yyyymmdd-hhmmss.csv

Where:

  • MTD identifies the file type
  • LLLLLLLL is your 8-digit UK provider reference number or UKPRN
  • YYYY is the calendar year, for example 2026
  • WW is the week number the data relates to, using ISO 8601 (link to ISO week numbers table)
  • yyyymmdd-hhmmss is the date and time the file was generated

ISO week numbers

Use the table to find the ISO week number for the reporting week your data relates to.

Week commencing Week ending Year ISO week
31 August 2026 6 September 2026 2026 36
7 September 2026 13 September 2026 2026 37
14 September 2026 20 September 2026 2026 38
Example

For data relating to the week commencing 14 September 2026, the ISO week number is 38.

If the file was generated on 20 September 2026 at 3:58:05pm, the file name would be:

MTD-10033670-2026-38-20260920-155805.csv
